## Sales Forecast Preparation

## Project Overview
This project focuses on preparing historical sales data for time-series analysis and forecasting using Python.

## Objective
To clean sales data, aggregate it into monthly periods, check for missing months, and visualize sales trends.

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab
- Microsoft Excel

## Dataset
Sample Superstore sales dataset containing order dates and sales amounts.

## Project Workflow
1. Load the sales dataset into Pandas.
2. Clean the data and convert dates into the correct format.
3. Handle invalid or missing values.
4. Aggregate sales data by month.
5. Check for missing monthly periods.
6. Create a monthly sales trend chart.
7. Export the prepared time series to CSV.

## Deliverables
- `prepared_sales_timeseries.csv` — Prepared monthly sales data.
- `sales_trend.png` — Monthly sales trend chart.
- `Day11_Sales_Forecast.ipynb` — Google Colab notebook.
- `Day11_Sales_Forecast_Preparation_Project_Report.pdf` — Project report.
